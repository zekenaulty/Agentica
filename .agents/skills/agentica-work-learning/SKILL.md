# Agentica learning from work

Keep the user's governing objective and requested acceptance intact while changing implementation or recovering a failed execution window. A component, fixture or receipt can prove its own boundary without proving the whole requested system.

Use agentica-contract-work for runtime contracts. Start at docs/Agentica.RuntimeContracts.md and the named runtime/client symbol, not the full design corpus. Current source and focused tests establish implementation.

Read .agents/learning/MEMORY.md and search only relevant records. With the global work-learning skill installed, use its helper with --scope agentica; useful queries include: agentic completion host integration; streaming provider context budget. It merges global preferences, this domain's canonical records and the shared inbox across isolated worktrees. Add --repo <this-working-copy> to include a branch's local records. Otherwise use targeted rg over .agents/learning/records and inspect the matching JSON directly.

Before applying an old technical lesson, inspect its evidence pin and recheck condition against the current source. User preferences and technical observations have different evidence requirements. A missing search result does not prove the domain lacks that capability.

Capture a new correction or verified technique once in the shared inbox through work-learning, without changing a peer checkout. Publish an accepted domain record in this working copy only when the evidence warrants it; keep raw progress in the existing task ledger. Include the source revision, exact proof level, domain assumptions and what would invalidate the result. Reuse the existing scope and record contract in .agents/learning/scope.json and the global work-learning reference. Keep project vocabulary and participant data out of global preferences.

This is development guidance for Codex agents working on Agentica. It does not mount a runtime faculty, update participant memory, publish Cloud work or establish that a running product has learned the lesson.
