## Reconciled direction

Use one small semantic expression: satisfy a versioned acceptance contract for a host subject within a scope/perspective, given admissible evidence, when validity/readiness permits, using a compatible realization when resolved; return typed result, evidence and residual obligations. WHAT/WHY/WHERE/WHEN/HOW and attributable WHO remain coordinates. Four transformation coordinates remain requires, produces, applies and effects. Six conceptual composition forms remain Perform, Visit, Choose, Gather, Repeat and Await; this report does not claim those are current executable APIs.

Obligation identity and governing acceptance survive provider changes, realization changes, decomposition, suspension and restart. Execution result, evidence coverage, obligation satisfaction, continuation and effect custody remain independent. A successful tool call, provider response or child task cannot silently satisfy an unresolved parent objective. An unknown original effect must be reconciled before a replacement is considered.

Agentica supplies bounded planning, validation, execution and proof. Hosts own canonical meaning, policy, source admissibility, durable attempts/state, persistence and domain effects. An installed/bound capability carries its standing scoped grant; selection within that grant requires no invented human approval. Discovery of an unbound descriptor differs from deliberate host installation. Technical unavailability or integrity failure blocks dispatch while preserving inspectable configuration.

Reuse stable definition structure and exact compatible interpretations. Recheck live evidence, source horizon, current grants/readiness, budgets and original attempts. Shared interpretation identity includes meaningful question, subject/source revisions, perspective, scope, coverage/horizon, ordering and compiler/generation policy. Consumer activation IDs and receipt times do not affect content identity. Each consumer separately accepts available evidence. A new relevant source can invalidate an old absence/completeness claim even when selected sources did not change.

First map the proposal onto existing `PlanningFrame`, `EvidenceRef`, `Artifact`, `TaskAcceptanceResult` and the runner. Add optional contracts only where two concrete hosts demonstrate a gap. Do not create a universal IR, new recursive scheduler or companion ontology merely to make design nouns into types.
